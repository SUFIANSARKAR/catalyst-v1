# Catalyst v5.7.0 — Enhanced Creator Admin Personality

## Enhanced admin mode

- Added an explicit Creator Admin gate for chat, streaming chat, enhanced reasoning, objective mutation, model changes, privileged tools, automation, device actions, and voice output.
- Normal mode remains a read-only/basic control-plane experience; it does not inherit Creator authority or the enhanced relationship/personality layer.
- Added a secure frontend unlock flow using the existing admin password/session endpoint.

## Personality

- Added a distinct Enhanced Catalyst personality: composed, proactive, emotionally attuned, strategic, lightly witty, evidence-aware, and concise without exposing private chain-of-thought.
- The personality is inspired by cinematic command-intelligence archetypes but is not an imitation of proprietary characters or voices.
- The model is explicitly instructed not to claim consciousness, physical presence, or literal human sensations.

## Voice

- Added a realistic adult-female voice presentation profile with provider-configurable voice, speech instructions, and cadence.
- Added optional provider-supported subtle breath cues at natural phrase or paragraph boundaries.
- Voice output is admin-gated and reports whether breath cues were actually supported by the configured provider.
- Added browser playback for the latest Catalyst response.

## Safety boundary

Admin mode does not bypass approvals, policy checks, secret protection, domain allowlists, or verification requirements. Breath cues are a voice-presentation effect; Catalyst does not literally breathe.
